ゲーム制作：ヨット

ゲームの概要

グループの中では、じゃんけんやおみくじといったゲームが作れそうと話していた。

遊び方

最初に再生ボタンを押すと、サイコロ五つが振られて結果が出る。その中から変えたい目を選んでもう一回振る。
この再抽選は三回までできる。

制作した内容

サイコロを使ったゲームの「ヨット」を作ろうと思った。
しかし、12個ある役目を全部作るのは大変だし、今の知識ではできないと思ったからゾロ目を狙うゲームにした。

うまくいかなかったこと


最初に作ったときは、写真のように思った通りの数字が変わってくれなかった。
写真では１，５，６の目を変えようとして数字を打っているが、コード的には１，５，６番目の数字が変わることになってしまっていた。

ソースコード

import random

print("===== ヨットゲーム =====")

dice = []
for roll in range(5):
    dice.append(random.randint(1, 6))

for turn in range(3):
    print("\n", turn + 1, "回目")
    print("サイコロ:", dice)

    if dice.count(dice[0]) == 5 or turn == 2:
        break

    while True:
        keep = input("残したい出目（例: 4 6、Enterで全部振り直し）：").split()
        valid = True
        for value in keep:
            if value not in ["1", "2", "3", "4", "5", "6"] or int(value) not in dice:
                valid = False
                break
        if valid:
            break
        print("今出ている目だけを入力してください。")

    for index in range(5):
        if str(dice[index]) not in keep:
            dice[index] = random.randint(1, 6)

print("\n===== 結果 =====")
print("最終的なサイコロ:", dice)

most = 0
for face in dice:
    count = dice.count(face)
    if count > most:
        most = count

if most == 5:
    print("ヨット！50点！")
elif most == 4:
    print("惜しい！あと1個でヨット！")
else:
    print("ヨットならず！")
